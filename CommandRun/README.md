**24 หมวด · 315 คำสั่ง**

## ความสามารถ
1. **แบ่งหมวด + คำอธิบายหมวด** — สารบัญด้านซ้าย (บนมือถือเลื่อนแนวนอน) แต่ละหมวดมีคำอธิบายว่าใช้ทำอะไร
2. **เติมค่าอัตโนมัติ** — กรอกข้อมูลที่แถบ "กรอกข้อมูล" (IP/DOMAIN/DC/USER/PASS/KALI/PORT/LPORT/RPORT/HASH/IFACE)
   แล้วทุกคำสั่งเติมค่าให้ทันที กดที่คำสั่งเพื่อคัดลอก
   - เว้นว่าง = แสดงเป็น `<ip>` `<user>` ให้เติมเอง
   - **กดที่ `<ip>` ในคำสั่งไหนก็ได้ → เด้งไปโฟกัสช่องกรอกนั้นเลย**
   - ค่าที่กรอกถูกจำไว้ใน localStorage
3. **ปุ่ม `?` ท้ายทุกคำสั่ง** — เปิดแผ่นอธิบายว่าแต่ละ flag ทำอะไร พร้อมแสดงค่าจริงที่กรอกไว้
4. **โหมดมืด / สว่าง** — สลับที่มุมขวาบน จำค่าไว้ และครั้งแรกจะตามการตั้งค่าเครื่อง
5. **คีย์ลัด** — กด `/` โฟกัสช่องค้นหา, `Esc` ปิดแผ่นอธิบาย
